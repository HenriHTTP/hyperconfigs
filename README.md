# CachyOS Dotfiles

Backup pessoal das configurações do CachyOS com Hyprland.

- config/: configurações dos aplicativos.
- system/: inventário de pacotes e sessão.
- docs/: documentação.
- private-local/: backups locais ignorados pelo Git.

Revise os arquivos antes de publicar. Não inclua credenciais ou chaves privadas.
